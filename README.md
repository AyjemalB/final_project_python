# Movie Search Console App
## Цель проекта:
Консольное приложение для поиска фильмов из базы данных sakila с возможностью поиска по ключевым словам, жанрам и годам, а также с сохранением всех поисковых запросов и выводом популярных запросов по частоте использования.

## Основной функционал:
- Поиск фильмов:
  - По ключевым словам (например, название фильма).
  - По жанру и году.
- Сохранение поисковых запросов в базе данных.
- Вывод списка самых популярных запросов. 

## Этапы разработки:
1. Изучение структуры базы данных и создание SQL-запросов.
2. Разработка консольного приложения с интерактивным пользовательским интерфейсом.
3. Реализация обработки ошибок и улучшения UI.

## Ключевые особенности:
- Интерактивная работа с пользователем.
- Разделение кода на модули: база данных, обработка команд, вывод данных.
- Поддержка обработки ошибок и информативные сообщения.

## Дополнительно:
- Документация с комментариями и инструкцией по установке.
- Код соответствует PEP 8 и структурирован для удобства сопровождения.

# Файлы проекта
В проекте используется 6 основных файлов, каждый из которых выполняет свою роль для обеспечения функциональности приложения:

1. db.py: 
   Содержит код для подключения к базе данных sakila как для чтения, так и для записи. Этот файл отвечает за взаимодействие с базой данных.

2. keyword_search.py: 
  В этом файле находится функция, которая позволяет искать фильмы по ключевому слову (например, по названию фильма).

3. film_search_by_genre_year.py: 
  Здесь реализована функция для поиска фильмов по жанру и году, что позволяет фильтровать результаты по этим параметрам.

4. keyword_logging.py: 
  В этом файле находится функция для записи всех поисковых запросов в базе данных и подсчёта повторяющихся ключевых слов. Это позволяет отслеживать самые популярные запросы.

5. popular_search_queries.py: 
  Этот файл содержит функцию для отображения самых популярных поисковых запросов. Если пользователь захочет, программа покажет список запросов, отсортированных по частоте.

6. main.py: 
  Это основной файл, который запускает приложение. Он обрабатывает ввод пользователя через консоль и использует все функции из других файлов для выполнения поиска, отображения результатов и   работы с базой данных.
  
Каждый файл проекта выполняет конкретную задачу, что позволяет разделить функционал и облегчить поддержку и развитие кода.

## Дополнительно:
7. requirements.txt: 
  Этот файл содержит список всех библиотек и зависимостей, которые использовались в проекте. Он позволяет легко установить все необходимые пакеты с помощью команды:
`pip install -r requirements.txt`
В файле перечислены все библиотеки, которые требуются для корректной работы приложения, обеспечивая удобство при установке и настройке окружения.
